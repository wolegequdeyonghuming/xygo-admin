## 1. 背景与目标

- **现状**：小程序原为通用的 `#336FFF` 蓝 + 白卡片 + `#F5F6F8` 冷灰底风格，层次扁平、无个性，与「外勤收单」业务场景缺乏关联；自定义导航未处理状态栏避让；无动效、无空态设计、无加载反馈。
- **目标**：在不改动业务逻辑与接口的前提下，对全部 7 个页面与 7 个共享组件进行视觉重设计，形成**浅色、清爽、可辨识**的统一风格，提升外勤场景下的可读性与操作效率。
- **约束**：
  - 小程序端无法可靠加载 Web 字体 → 依赖系统字族 + 字重/字距塑造层级。
  - WXSS 中 `calc()` 不支持乘法 → 动效定位使用 `transform: translateX(%)`。
  - 全部页面使用 `navigationStyle: custom` → 顶部需按状态栏高度避让。

---

## 2. 设计方向

**「Cobalt Ops · 清爽白 + 钴蓝」**：以浅冷灰蓝为底、纯白卡片承载内容、钴蓝作单一主强调色，深炭色文字保证阳光下可读。保留强辨识度的差异化元素：

- 统计舱：浅蓝渐变面板 + 超大数字 + 数字滚动动画 + 状态色发光导轨。
- 票据式订单卡：左侧状态色导轨 + 印章状态标签 + 大号客户名 + 字段网格。
- 浮动 Dock 底部导航：白色圆角坞 + 激活药丸滑移。
- 雷达空态：钴蓝同心波纹 + 脉冲光点。
- 错峰入场动画：订单卡按索引延迟淡入上移。

> 历史：初稿曾尝试「Field Deck 外勤工单舱」深色墨蓝主题，经评审调整为浅色方案；最终确认采用「清爽白 + 钴蓝」，并去除页面顶部系统名/日期等非必要标题栏。

## 3. 设计令牌

### 3.1 颜色

| 角色 | 色值 | 用途 |
|------|------|------|
| `--bg` 页面背景 | `#F4F6FA` | 浅冷灰蓝底 |
| `--card` 卡片 | `#FFFFFF` | 卡片 + 发丝边 `rgba(17,24,39,.06)` |
| `--cobalt` 主色 | `#2563EB` | 主按钮 / 链接 / 强调 |
| `--cobalt-dark` | `#1D4ED8` | 按钮按压态 |
| `--cobalt-soft` | `#E8EFFD` | 浅蓝 tint（药丸、提示、标签底） |
| `--ink` 主文字 | `#111827` | 标题 / 正文 |
| `--text-2` 次文字 | `#4B5563` | 说明 / 副标题 |
| `--text-3` 辅助文字 | `#9CA3AF` | 占位 / 弱化信息 |

### 3.2 状态色（`utils/status.js` 统一维护）

| 状态 | 色值 | 底 |
|------|------|-----|
| 0 未成交 | `#8A8F98` | `#E6E8EB` |
| 1 已录单 / 2 待预约 | `#E8930C` | `#FBEED7` |
| 3 待收单 | `#E5484D` | `#FCE3E4` |
| 4 已收单 / 5 已回访 / 6 已完工 | `#30A46C` | `#DCF0E6` |

> 已收单/回访/完工由原蓝色统一改为**绿色**（语义=已办结），便于一眼识别完成态。

### 3.3 圆角 / 阴影

| 令牌 | 值 |
|------|-----|
| 卡片圆角 | 24–28rpx |
| 按钮圆角 | 24rpx |
| 标签圆角 | 16rpx |
| 卡片阴影 | `0 6rpx 24rpx rgba(17,24,39,.06)` |
| 强调阴影 | `0 12–16rpx 28–48rpx rgba(37,99,235,.12–.30)` |

令牌定义于 `App.vue`（CSS 变量）与 `uni.scss`（SCSS 变量，兼容旧变量名）。wot-design-uni 主题色通过 `--wot-color-theme` 同步为钴蓝。

## 4. 字体规范

- 字族：`PingFang SC / HarmonyOS Sans SC / MiSans / Helvetica Neue / Arial`。
- 字重阶梯（避免正文滥用加粗）：

| 场景 | 字重 |
|------|------|
| 统计数字（数字主角） | 800 |
| 页面/分节标题 | 700 |
| 大号客户名 / 用户名 | 700 |
| 业务名 / 按钮 / 印章标签 | 600–700 |
| 表单标签 / 快操作 | 500 |
| 字段值 / 正文 | 400 |
| 辅助文字 | 400 |

## 5. 组件设计规范

| 组件 | 规范 |
|------|------|
| `tab-bar` | 白色浮动圆角坞（左右 32rpx、底部 24rpx + safe-area）；激活药丸 `#E8EFFD` 用 `transform: translateX(index*100%)` 滑移；选中图标+文字深色 `#111827`，未选中灰 `#9CA3AF`；`z-index` 保证药丸在图标之下 |
| `stat-cards` | 浅蓝渐变面板 + 顶部钴蓝光晕；每项数字用状态色 + `tnum` 等宽；选中项全彩 + 状态色发光导轨，未选中降透明 50%；数字滚动动画（easeOutCubic，700ms） |
| `order-tag` | 印章标签：圆点 + 斜切角 `clip-path`；色板见 3.2 |
| `order-card` | 票据式：左侧状态色导轨 + 标签/业务名/单号 + 大号客户名 + 双列字段网格（电话、预约时间、办理地址、收单员）+ 电话/地址可点钴蓝链接；紧凑布局（内边距 24/18、字段行距 16/20、卡片间距 28）；错峰入场动画 `cardUp` |
| `bottom-action` | 钴蓝主按钮（阴影/按压变深）+ 浅灰次按钮；按压缩放 0.97 |
| `detail-section` | 白卡分节：标题前钴蓝嵌线；label 辅助色、val 正文色、链接钴蓝 |
| `order-comment` | 白卡 + 标题嵌线 + 时间线列表（钴蓝节点 + 光晕）；「添加详情」钴蓝软底胶囊；弹窗浅色 |

## 6. 页面设计规范

| 页面 | 规范 |
|------|------|
| 首页 `order/list` | 浅蓝渐变舱头（网格纹理 + 钴蓝光晕），仅含用户行（头像/姓名/角色/箭头），状态栏避让；统计舱上叠于舱头（`margin-top: -36rpx`）；列表标题行 + 月选择 chip；雷达空态 |
| 查询 `order/query` | 无标题栏（状态栏 spacer）；搜索行：白卡状态选择 + 白卡姓名输入 + **钴蓝筛选按钮（白图标）**；筛选弹窗浅色化（浅底字段/日期/区县 + 钴蓝确定按钮）；雷达空态 |
| 详情 `order/detail` | 票据主卡 + 分节卡（预约/收单/回访/完工，按状态渐进展示）+ 附件网格/文件行 + 底部操作栏（safe-area）+ 排单/完工弹窗浅色化 |
| 预约 `order/appoint` | 只读信息卡 + 编辑卡（上门日期 + 预约情况文本域）+ 底部提交按钮 |
| 收单 `order/collect` | 只读信息卡 + 预约情况 + 收单编辑卡（12 字段 + 分段控件 + 附件网格，虚线占位 + 删除角标）+ 暂存/完成双按钮 |
| 我的 `user/index` | 浅蓝舱头（头像/姓名/角色）+ 信息卡（手机号/岗位/部门，分割线行）+ 退出登录 |
| 登录 `login/index` | 浅蓝渐变全屏 + 双光晕；白卡表单（浅底输入框）+ 钴蓝登录按钮 + 底部协议 |

## 7. 动效规范

- 订单卡入场：`cardUp`（opacity + translateY），按索引错峰 `min(index,6)*90ms`。
- 统计数字：easeOutCubic 滚动，700ms，`requestAnimationFrame`（无则 16ms 降级）。
- Dock 药丸：`transform` 过渡 0.28s。
- 交互反馈：卡片/按钮/胶囊按压缩放；选中态透明度过渡。
- 空态雷达：同心环 `ringPulse` 呼吸动画。
- 全为 CSS transform/opacity，保证小程序端性能。

## 9. 实施记录

### 9.1 实施范围（已完成）

- **全局**：`App.vue`（CSS 令牌 + wot 主题）、`uni.scss`（SCSS 令牌）、`pages.json`（背景色）、`utils/status.js`（状态色板）、`utils/system.js`（状态栏高度）。
- **组件（7 个全做）**：`tab-bar`、`stat-cards`、`order-tag`、`order-card`、`bottom-action`、`detail-section`、`order-comment`。
- **页面（7 个全做）**：首页、查询、详情、预约、收单、我的、登录。

### 9.2 迭代记录

| 轮次 | 反馈 | 处理 |
|------|------|------|
| 1 | 原蓝白灰风格平淡，需出方案 | 初拟「Field Deck 外勤工单舱」深色方向 |
| 2 | 不要暗黑风格、不要只做一半 | 改为浅色主题；一次全量实施 7 组件 + 7 页面 |
| 3 | 去掉系统名/时间标题栏 | 首页删系统名/日期栏，仅留用户行；清理无用代码 |
| 3 | 底部 tab 选中态不显示 | 修复 `calc()` 乘法兼容问题 → `transform: translateX(%)`；选中项改深色图标+文字 |
| 3 | 去掉一部分加粗 | 统一字重阶梯：字段值 400、业务名 600、客户名 700、分节标题 700、标签 500 |
| 4 | 去掉 LIVE 字样 | 统计舱删除 LIVE 圆点+文字，选中态由全彩+导轨发光体现 |
| 4 | 订单卡紧凑、去掉致电/复制按钮 | 移除快操作胶囊，收紧布局；电话/地址仍可通过字段链接拨号/复制 |
| 4 | 底部药丸盖住图标文字 | `.pill` `z-index:0`，`.dock-item` `z-index:1` |
| 4 | 筛选图标与按钮同色不可见 | 图标改白色 `#FFFFFF` |

## 10. 校验与预览

- H5：`pnpm build:h5`（产物 `dist/build/h5/`），开发态 `pnpm dev:h5`。
- 微信小程序：`pnpm build:mp-weixin`（产物 `dist/build/mp-weixin/`），用微信开发者工具导入运行。
- 校验要求：两次构建均通过；H5 浏览器预览 + 微信开发者工具核对。
