Pixso 原型演示 - 使用前必读

请先完整解压整个文件夹，再启动程序。
不要单独移动、删除或重命名文件夹里的任何文件，否则可能导致页面空白、图片缺失或无法启动。


一、Windows 启动方式

1. 打开解压后的文件夹。
2. 双击“启动-windows.exe”。
3. 程序会启动本地 WASM 安全服务，并自动打开默认浏览器。
4. 浏览器打开后即可查看“原型演示”页面。
5. 如果浏览器没有自动打开，请查看启动窗口中“手动访问地址”后面的本地地址，复制到 Chrome 或 Edge 浏览器中打开。

Windows 可能出现的弹窗：

- 如果出现黑色启动窗口：这是正常的本地服务窗口，请不要关闭。
- 如果出现“Windows 已保护你的电脑”：点击“更多信息”，再点击“仍要运行”。
- 如果出现 Windows Defender 防火墙提示：选择“允许访问”。建议只勾选“专用网络”，不需要勾选“公用网络”。
- 如果安全软件拦截启动程序：请确认文件来源可信后加入信任；如果不确定，请把拦截截图发给Pixso客服排查。


二、Mac 启动方式

重要：Mac 上收到 zip 压缩包后，请在 Finder 中双击压缩包解压。
不要直接在压缩包预览中运行启动程序，也不建议用命令行解压。

1. 解压后打开文件夹。
2. 根据电脑芯片选择启动程序：
   - 苹果芯片 Mac（M1 / M2 / M3 / M4）：双击“启动-mac-m1”。
   - Intel 芯片 Mac：双击“启动-mac-intel”。
3. 如果不确定电脑芯片类型，请点击左上角苹果菜单 > 关于本机，查看“芯片”或“处理器”。
4. 程序会启动本地 WASM 安全服务，并自动打开默认浏览器。
5. 浏览器打开后即可查看“原型演示”页面。
6. 如果浏览器没有自动打开，请查看启动窗口中“手动访问地址”后面的本地地址，复制到 Chrome 或 Safari 浏览器中打开。

Mac 可能出现的安全提示和解决方式：

- 如果提示“无法验证开发者”或“无法打开”：按住 Control 键点击对应的启动程序，选择“打开”，在弹窗中再次点击“打开”。
- 如果仍然被拦截：打开“系统设置” > “隐私与安全性”，在安全提示区域点击“仍要打开”。
- 如果提示“权限不足”或双击没有反应：需要给启动程序增加执行权限。

给 Mac 启动程序增加执行权限：

1. 打开“终端”。
2. 输入下面的命令，注意x后有一个空格：
   chmod +x 
3. 把要启动的文件拖进终端窗口，例如“启动-mac-m1”或“启动-mac-intel”。
4. 按回车执行。
5. 回到 Finder，再次双击启动程序。

示例命令：
chmod +x /你的解压目录/启动-mac-m1
chmod +x /你的解压目录/启动-mac-intel

如果 Mac 提示文件“已损坏”或仍无法通过安全检查，并且你确认文件来源可信，可以在终端执行：

xattr -dr com.apple.quarantine /你的解压目录

建议把整个解压后的文件夹拖到命令末尾，避免手动输入路径错误。执行后再按上面的方式双击打开。


三、安全说明

- 启动程序只会在本机启动一个本地服务，地址通常是 http://127.0.0.1:端口号/。
- 127.0.0.1 只允许当前电脑自己访问，不会对局域网或互联网开放。
- 端口号由程序自动分配，请以启动窗口显示为准。
- 演示资源都在当前文件夹中，一般不需要联网。
- 关闭浏览器演示页面后，本地服务会自动退出；需要再次查看时重新双击启动程序。


四、使用时注意

- 请确认文件为通过Pixso官方下载得到的压缩包，若无法确认来源请不要继续运行。
- 启动后请不要关闭启动窗口；关闭启动窗口会停止原型演示服务。
- 请保持以下内容和启动程序放在同一个文件夹内：
  assets、document、fonts、runtime、presentation-assets、manifest.json、pixso.binary、index.html。
- 如果页面长时间加载或出现空白，请先关闭启动窗口，再重新双击对应的启动程序。
- 如果仍然无法打开，请把电脑系统、点击的启动文件名、启动窗口提示或截图以及压缩包发给Pixso客服，我们会尽快为您排查。
