# 用户操作手册 · 权限管理

> 适用对象：普通管理员（负责创建用户、分配角色、维护菜单/部门/岗位）
>
> 本手册介绍系统「权限管理」模块的用法，重点说明如何**创建用户、分配角色**，以及各业务角色的权限含义。权限配置是否正确，直接决定业务人员能否正常使用订单等功能。

## 1. 权限管理入口

登录后台后，在左侧菜单中找到 **「权限管理」** 分组，包含以下功能：

| 菜单 | 用途 |
|------|------|
| 用户管理 | 创建、编辑、删除用户，分配角色 |
| 角色管理 | 新建、编辑角色，分配菜单/数据/字段权限 |
| 菜单管理 | 维护系统菜单、页面与按钮权限 |
| 部门管理 | 维护组织架构 |
| 岗位管理 | 维护岗位信息 |

> 说明：本手册重点关注「用户管理」和「角色管理」；「菜单管理」「部门管理」「岗位管理」通常在系统初始化时配置完毕，日常使用较少。

## 2. 用户管理

### 2.1 进入页面

左侧菜单：**权限管理 → 用户管理**。

页面以表格展示所有用户，包含：头像与用户名、昵称、性别、手机号、邮箱、角色、在线状态、状态、创建时间。

### 2.2 搜索用户

顶部搜索栏支持按以下条件筛选：

- 用户名
- 手机号
- 邮箱
- 状态（启用 / 停用）
- 性别

设置条件后点击「搜索」，点击「重置」清空条件。

### 2.3 新增用户

1. 点击右上角「新增用户」。
2. 填写表单：

| 字段 | 是否必填 | 说明 |
|------|---------|------|
| 用户名 | 是 | 登录账号，2-20 个字符；**创建后不可修改** |
| 昵称 | 否 | 显示昵称 |
| 密码 | 是（新增） | 登录密码，至少 6 位；编辑时留空则不修改 |
| 性别 | 否 | 男 / 女 |
| 手机号 | 否 | 手机号码 |
| 邮箱 | 否 | 电子邮箱 |
| 头像 | 否 | 用户头像 |
| 部门 | 否 | 从部门树中选择所属部门 |
| 角色 | 否 | **多选**，从角色列表勾选（见 [3. 角色管理](#3-角色管理)） |
| 岗位 | 否 | 多选岗位 |
| 状态 | 否 | 启用 / 停用 |

3. 点击「保存」。

### 2.4 编辑用户

1. 在用户列表中，点击目标行操作列的「编辑」。
2. 修改表单内容（用户名不可修改）。
3. 点击「保存」。

### 2.5 删除用户

1. 点击目标行操作列的「删除」。
2. 按提示确认后删除。

> 注意：删除用户前请确认其名下业务已处理或转移，删除后该用户无法登录。

### 2.6 下线用户

点击目标行操作列的「下线」，可强制将已登录的用户踢出系统（适合账号被盗用或需要立即失效的场景）。

## 3. 角色管理

### 3.1 进入页面

左侧菜单：**权限管理 → 角色管理**。

角色以树形表格展示，包含：角色 ID、角色名称、角色标识、描述、状态、创建时间。

### 3.2 新建角色

1. 点击「添加角色」，打开角色编辑弹窗。
2. 填写表单：

| 字段 | 是否必填 | 说明 |
|------|---------|------|
| 角色名称 | 是 | 角色的显示名称，如「话务员」 |
| 角色标识（key） | 是 | 角色唯一编码，**只能使用小写字母和下划线**（如 `telemarketer`）；**必须与业务代码一致**，详见 [4. 订单相关角色与权限说明](#4-订单相关角色与权限说明) |
| 角色描述 | 否 | 角色用途说明 |
| 排序 | 否 | 显示顺序 |
| 启用 | 否 | 是否启用该角色 |

3. 点击「保存」。

> ⚠️ **特别提醒**：订单等业务功能是按「角色标识 key」判断权限的，新建角色时如果 key 与系统约定不一致，业务功能将不生效。例如要创建「话务员」角色，角色标识必须填 `telemarketer`（不是 `huwuyuan`、`话务员` 等）。

### 3.3 编辑角色

在角色行操作列的「更多」下拉中点击「编辑」，修改后保存。

> 说明：系统内置的「超级管理员（super_admin）」角色不可编辑、不可删除。

### 3.4 删除角色

在「更多」下拉中点击「删除」，确认后删除。删除前请先确认没有用户使用该角色。

### 3.5 分配菜单权限

1. 在角色行操作列「更多」中点击「菜单权限」。
2. 在菜单树中勾选该角色可访问的菜单/页面/按钮权限。
3. 可使用「全部展开 / 全部收起」「全部选择 / 取消全选」快捷操作。
4. 点击「确定」保存。

> 说明：用户登录后只能看到其角色勾选的菜单；按钮级权限（如「新增 / 导出」）也由此控制。

### 3.6 数据权限与字段权限

- **数据权限**：控制该角色能看到哪些数据范围（如仅本人、本部门、全部等）。订单业务的可见性已在业务代码中硬编码，不受此设置影响。
- **字段权限**：控制某些字段是否可见。当前订单业务未使用字段权限。

### 3.7 添加子角色

点击行内「添加子角色」，可在某角色下创建下级角色（子角色会继承父角色关系）。

## 4. 订单相关角色与权限说明

> 这是权限配置中**最重要**的一节。以下角色的「角色标识 key」必须与系统约定**完全一致**，否则用户无法正常使用订单功能。

### 4.1 订单 6 步流程与角色对应

| 环节 | 角色 | 角色标识 key（必须一致） | 说明 |
|------|------|----------------------|------|
| 录单 | 话务员 | `telemarketer` | 录入客户信息，创建订单 |
| 派单 | 收单员管理员 | `agent_manager` | 为订单指派收单员 |
| 预约 | 收单员 | `agent` | 填写收单预约情况 |
| 收单 | 收单员 | `agent` | 填写上门及成交信息 |
| 回访 | 话务员 | `telemarketer` | 填写二次回访情况 |
| 完成 | 财务文员 | `documentary` | 填写宽带账号、工号、是否完工 |
| 全流程 | 管理员 | `admin` | 可执行任意环节 |

### 4.2 订单数据可见性

| 角色标识 key | 可见范围 |
|-------------|---------|
| `telemarketer` / `telemarketer_manager` | 只能看到自己录入的订单 |
| `agent` | 只能看到派给自己的订单 |
| `agent_manager` / `documentary` / `admin` | 可以看到全部订单 |

### 4.3 角色层级建议

按系统初始化约定，订单相关角色建议按以下层级创建：

| 父角色 | 子角色 |
|--------|--------|
| 话务员管理员（`telemarketer_manager`） | 话务员（`telemarketer`） |
| 收单员管理员（`agent_manager`） | 收单员（`agent`） |
| 管理员（`admin`） | —（独立顶级角色） |
| 财务文员（`documentary`） | —（独立顶级角色） |

### 4.4 角色用途速查表

| 角色标识 key | 角色名称（示例） | 主要负责 |
|-------------|----------------|---------|
| `admin` | 管理员 | 全流程处理，可查看/删除任意订单 |
| `telemarketer_manager` | 话务员管理员 | 录单、回访；管理话务员 |
| `telemarketer` | 话务员 | 录单、回访（只看自己录的订单） |
| `agent_manager` | 收单员管理员 | 派单；管理收单员 |
| `agent` | 收单员 | 预约、收单（只看派给自己的订单） |
| `documentary` | 财务文员 | 订单完成环节 |

## 5. 菜单管理

左侧菜单：**权限管理 → 菜单管理**。

菜单树用于维护系统的导航结构。每个菜单分为三种类型：

| 类型 | 说明 | 关键字段 |
|------|------|---------|
| 目录 | 一级导航分组 | 路由地址、权限标识、图标 |
| 菜单 | 具体页面 | 路由地址、组件路径、权限标识、关联数据表 |
| 按钮 | 页面内的操作权限（如新增/编辑/删除/导出） | 权限名称、权限标识、接口权限点 |

### 5.1 新增菜单

1. 点击「添加菜单」，先选择类型（目录 / 菜单 / 按钮）。
2. 填写对应字段（名称、上级菜单、路由地址、权限标识、图标、排序、是否启用等）。
3. 点击「保存」。

### 5.2 按钮权限与页面按钮的关系

- 页面顶部的「新增」「导出」等按钮，是否显示由对应**按钮权限**控制。
- 例如「导出」按钮对应权限标识 `export`，用户所属角色需在「菜单权限」中勾选该按钮权限后，才能看到并点击导出。

> 说明：菜单管理通常由系统管理员在初始化时配置完成，日常维护较少；如无必要请勿随意修改。

## 6. 部门管理

左侧菜单：**权限管理 → 部门管理**。

用于维护组织架构（如：总公司 → 市场部 → 话务团队）：

- **新增部门**：点击「添加部门」，填写部门名称、排序、状态、备注。
- **添加子部门**：在部门行点击「添加子部门」，创建下级部门。
- **编辑 / 删除**：在部门行操作列操作。

部门用于用户信息中的归属展示，也用于人员选择器（如派单时按部门选择收单员）。

---

## 7. 岗位管理

左侧菜单：**权限管理 → 岗位管理**。

用于维护岗位信息（岗位名称、编码、排序、状态）。岗位可分配给用户（多选），通常作为人员标签使用，不影响订单业务权限。

## 8. 完整操作流程示例

下面以「新增一名话务员并赋予录单/回访权限」为例，演示完整流程：

1. **确认角色已存在**：进入「角色管理」，确认存在角色标识为 `telemarketer` 的角色。
   - 若不存在：点击「添加角色」，角色名称填「话务员」，**角色标识填 `telemarketer`**，点击「保存」。
   - 然后：在该角色「更多 → 菜单权限」中勾选订单相关菜单（如「订单主表」及其操作按钮），保存。

2. **确认部门已存在**（可选）：进入「部门管理」，确保有对应部门（如「市场部 → 话务团队」），没有则新建。

3. **创建用户**：进入「用户管理」，点击「新增用户」，填写用户名、密码，在「角色」中选择「话务员」角色，点击「保存」。

4. **验证登录**：使用新用户名、密码登录，确认能看到「订单主表」菜单，并能使用录单、回访等功能。

> 提示：如果新用户登录后看不到订单菜单或按钮，请检查：① 该用户是否已分配角色；② 角色标识 key 是否为 `telemarketer`；③ 角色是否已勾选对应菜单/按钮权限。

## 9. 常见问题

**Q1：新建用户后，用户登录提示无权限或看不到菜单？**
答：请按顺序检查：① 用户是否分配了角色；② 角色的「菜单权限」是否勾选了所需菜单和按钮；③ 角色标识 key 是否与业务约定一致（见 [4. 订单相关角色与权限说明](#4-订单相关角色与权限说明)）。

**Q2：角色标识（key）填错了怎么办？**
答：进入「角色管理」，在该角色「编辑」中修改「角色标识」，保存即可。注意修改后旧标识下的业务判断会立即切换。

**Q3：为什么订单角色填了中文名称不行？**
答：订单业务按「角色标识 key」判断权限，key 只能是小写字母和下划线（如 `telemarketer`）。角色「名称」可以任意，但「标识」必须与系统约定一致。

**Q4：超级管理员角色能否修改？**
答：不能。系统内置「超级管理员（super_admin）」角色受保护，不可编辑、不可删除、不可修改其菜单/数据/字段权限。

**Q5：如何快速让一个用户拥有全部订单权限？**
答：给该用户分配「管理员（`admin`）」角色即可（管理员可见全部订单并可执行任意环节）。或者为其分配对应环节的角色组合（如话务员 + 收单员管理员 + 财务文员）。
