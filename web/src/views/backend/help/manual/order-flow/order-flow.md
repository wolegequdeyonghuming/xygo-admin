> 本手册介绍「订单主表」从**录入到完工**的完整处理流程，包括各环节的操作入口、填写字段、保存与状态推进，以及订单的查看、导出、删除和数据可见性说明。

## 1. 登录与导航

1. 打开浏览器，访问系统后台地址（由管理员提供）。
2. 在登录页输入**用户名**、**密码**，并按要求点选**验证码**，点击「登录」。
3. 登录成功后进入「工作台」首页。
4. 在左侧菜单中点击 **「订单管理 → 订单主表」**，进入订单列表页面。

> 说明：不同角色登录后，看到的菜单和订单数据范围可能不同，具体见 [2. 订单流程与角色总览](#2-订单流程与角色总览)。

## 2. 订单流程与角色总览

一张订单从录入到完工，依次经过 **6 个步骤**，每个步骤由特定角色负责：

| 步骤 | 环节 | 操作角色 | 目标状态 |
|------|------|---------|---------|
| 1 | 录单 | 话务员 / 话务员管理员 | 已录单 |
| 2 | 派单 | 收单员管理员 | 已接单 |
| 3 | 预约 | 收单员 / 收单员管理员 | 已预约 |
| 4 | 收单 | 收单员 / 收单员管理员 | 已上门 |
| 5 | 回访 | 话务员 / 话务员管理员 | 已回访 |
| 6 | 完成 | 财务文员 / 管理员 | 已完工 |

### 订单状态说明

| 状态值 | 状态名称 | 含义 |
|--------|---------|------|
| 0 | 未成交 | 终止态（暂未使用，预留） |
| 1 | 已录单 | 话务员已录入客户信息 |
| 2 | 已接单 | 已指派收单员 |
| 3 | 已预约 | 已与客户预约 |
| 4 | 已上门 | 收单员已上门处理 |
| 5 | 已回访 | 话务员已二次回访 |
| 6 | 已完工 | 已完成，可查看宽带账号、工号等 |

### 数据可见性

不同角色只能看到权限范围内的订单：

| 角色 | 可见范围 |
|------|---------|
| 话务员 / 话务员管理员 | 只能看到**自己录入**的订单 |
| 收单员 | 只能看到**派给自己**的订单 |
| 收单员管理员 / 财务文员 / 管理员 | 可以看到**全部**订单 |

> 注意：收单员管理员虽可查看全部订单，但**预约、收单仅限收单员为自己**的订单（派单不受此限）。

## 3. 订单列表页

进入「订单主表」后，页面从上到下依次为：**搜索栏 → 工具栏 → 数据表格**。

### 3.1 搜索栏

可按以下条件筛选订单：

- 订单状态（未成交 / 已录单 / 已接单 / 已预约 / 已上门 / 已回访 / 已完工）
- 排单日期（起止）
- 上门日期（起止）
- 客户姓名（模糊搜索）
- 区县
- 安装地址（模糊搜索）
- 联系电话（模糊搜索）
- 预约业务（模糊搜索）

设置条件后点击「搜索」；点击「重置」清空条件。

### 3.2 工具栏（顶部按钮）

| 按钮 | 说明 | 可见角色 |
|------|------|---------|
| 录单 | 新建一笔订单并进入第 1 步录单 | 话务员 / 话务员管理员 / 管理员 |
| 新增 | 全字段新增（直接填写所有信息） | 有「新增」权限的角色 |
| 导出 | 按当前搜索条件导出为 Excel 文件 | 有「导出」权限的角色 |

### 3.3 操作列按钮

每条订单行右侧的操作按钮**根据订单状态和当前角色动态显示**：

| 按钮 | 说明 |
|------|------|
| 录单 | 订单处于「已录单」阶段时，话务员可再次修改录单信息 |
| 派单 | 订单处于「已录单」阶段时，收单员管理员可指派收单员 |
| 预约 | 订单处于「已接单」阶段时，收单员可填写预约情况 |
| 收单 | 订单处于「已预约」阶段时，收单员可填写上门及成交信息 |
| 回访 | 订单处于「已上门」阶段时，话务员可填写二次回访情况 |
| 完成 | 订单处于「已回访」阶段时，财务文员可填写完成信息 |
| 查看 | 打开订单详情页 |
| 编辑 | 全字段编辑（管理员 / 财务文员） |
| 删除 | 删除订单（按角色和状态限制，见 [第 8 节](#8-删除与数据可见性)） |

> 说明：点操作按钮会打开对应的**步骤弹窗**，在弹窗中填写该环节的字段。每个环节都可以多次保存修改。

## 4. 分步操作详解

> 所有步骤弹窗底部通常提供两个保存按钮：
> - **「保存」**：仅保存当前环节填写的字段，**订单状态保持不变**（可先留存，稍后再继续）。
> - **「保存并下一步」**：保存当前环节字段，并**将订单推进到下一状态**；仅当您的角色有权限执行该推进时才显示。
>
> 弹窗底部还会显示该订单的「详细情况」评论区，详见 [第 5 节](#5-详细情况评论区)。

### 4.1 录单（话务员）

**入口**：列表顶部「录单」按钮，或已录单订单操作列的「录单」按钮。

**填写字段**：

| 字段 | 是否必填 | 说明 |
|------|---------|------|
| 排单日期 | 否 | 计划排单日期 |
| 客户姓名 | 是 | 客户名称 |
| 可联系时间 | 否 | 客户方便联系的时间段 |
| 区县 | 否 | 从下拉选择 |
| 安装地址 | 否 | 客户安装地址 |
| 联系电话 | 是 | 客户联系电话 |
| 预约业务 | 否 | 如「159+fttr」等 |
| 到期时间 | 否 | 业务到期时间 |

**操作步骤**：

1. 点击「录单」，打开录单弹窗。
2. 填写客户信息（带 `*` 的为必填项）。
3. 点击「保存」，订单创建成功，状态变为「已录单」。

> 说明：
> - 话务员录单后订单即为「待排单」，等待收单员管理员派单；话务员的录单弹窗只显示「保存」按钮（话务员无派单权限，故不显示「保存并下一步」）。
> - 录单时系统会自动将当前登录用户记录为本订单的话务员。

### 4.2 派单（收单员管理员）

**入口**：已录单订单操作列的「派单」按钮。

**填写字段**：

| 字段 | 是否必填 | 说明 |
|------|---------|------|
| 收单员 | 是 | 从人员选择器中选择负责该订单的收单员 |

**操作步骤**：

1. 点击「派单」，打开派单弹窗。
2. 点击「收单员」输入框，按部门树展开，选择一名收单员。
3. 点击「保存并下一步」，订单状态变为「已接单」。

> 说明：派单后，该收单员登录即可在列表中看到这笔订单。

### 4.3 预约（收单员）

**入口**：已接单订单操作列的「预约」按钮。

**填写字段**：

| 字段 | 是否必填 | 说明 |
|------|---------|------|
| 收单预约情况 | 否 | 与客户预约的时间、方式、事项等 |

**操作步骤**：

1. 点击「预约」，打开预约弹窗。
2. 填写收单预约情况。
3. 点击「保存并下一步」，订单状态变为「已预约」。

### 4.4 收单（收单员）

**入口**：已预约订单操作列的「收单」按钮。

**填写字段**：

| 字段 | 是否必填 | 说明 |
|------|---------|------|
| 上门日期 | 否 | 实际上门日期 |
| 成交业务 | 否 | 最终成交的业务 |
| 携转情况 | 否 | 携号转网等情况 |
| 客户实际姓名 | 否 | 客户实际姓名（如与录单时不同） |
| 客户身份证号 | 否 | 客户身份证号码 |
| 实缴额度 | 否 | 实际缴纳金额（元） |
| 是否乡下单 | 否 | 选择「是 / 否」 |
| 新开号码 | 否 | 新开号码 |
| 终端串码 | 否 | 终端设备串码 |
| 话补 | 否 | 话费补贴金额（元） |
| 是否纯新增 | 否 | 是否纯新增业务 |
| 附件 | 否 | 可上传最多 5 个文件（图片 / 文档等） |

**操作步骤**：

1. 点击「收单」，打开收单弹窗。
2. 填写上门及成交相关信息，如需上传材料点击「附件 → 选择文件」或「上传文件」。
3. 点击「保存并下一步」，订单状态变为「已上门」。

### 4.5 回访（话务员）

**入口**：已上门订单操作列的「回访」按钮。

**填写字段**：

| 字段 | 是否必填 | 说明 |
|------|---------|------|
| 话务二次回访情况 | 否 | 回访结果、客户反馈等 |

**操作步骤**：

1. 点击「回访」，打开回访弹窗。
2. 填写话务二次回访情况。
3. 点击「保存并下一步」，订单状态变为「已回访」。

### 4.6 完成（财务文员）

**入口**：已回访订单操作列的「完成」按钮。

**填写字段**：

| 字段 | 是否必填 | 说明 |
|------|---------|------|
| 宽带账号 | 否 | 宽带账号 |
| 工号 | 否 | 对应工号 |
| 是否完工 | 否 | 选择「未完工 / 已完工」 |

**操作步骤**：

1. 点击「完成」，打开完成弹窗。
2. 填写宽带账号、工号，选择是否完工。
3. 点击「保存并下一步」，订单状态变为「已完工」，流程结束。

## 5. 详细情况（评论区）

每笔订单都带有一个「详细情况」区域（类似评论区），供相关人员在订单推进过程中补充说明，并**保留操作记录**。

**展示位置**：

- 订单详情页底部
- 每个步骤弹窗底部

**可执行的操作**：

| 操作 | 说明 |
|------|------|
| 查看最新一条 | 折叠区默认显示最新一条详细情况 |
| 增加详情 | 点击「增加详情」展开输入框，填写后点「保存」 |
| 查看全部 | 点击「全部详细情况 (数量)」打开弹窗查看完整列表 |
| 删除 | 只能删除**自己录入**的详细情况 |

> 说明：只要能看到该订单，就可以为其增加详细情况；删除仅限本人录入的记录，且为逻辑删除（不可恢复）。

## 6. 查看订单详情

点击订单操作列的「查看」按钮，打开**订单详情页**。页面按步骤分区展示：

| 分区 | 内容 |
|------|------|
| 顶部概览 | 订单状态、话务员、收单员、创建时间、更新时间 |
| 录单信息 | 排单日期、客户姓名、可联系时间、联系电话、区县、安装地址、预约业务、到期时间 |
| 预约信息 | 收单预约情况 |
| 收单信息 | 上门日期、成交业务、携转情况、客户实际姓名、客户身份证号、实缴额度、是否乡下单、主卡号码、新开号码、终端串码、话补、是否纯新增、附件 |
| 回访信息 | 话务二次回访情况 |
| 完成信息 | 宽带账号、工号、是否完工、备注 |
| 详细情况 | 评论区（见 [第 5 节](#5-详细情况评论区)） |

**附件预览**：收单信息中的「附件」以缩略图卡片展示，图片点击可放大预览，非图片文件点击可打开或下载。

## 7. 导出订单

1. 在订单列表页按需设置**搜索条件**（也可不设，导出全部）。
2. 点击工具栏「导出」按钮。
3. 系统按当前筛选条件生成 Excel 文件，浏览器自动下载。

> 说明：导出文件基于「移动业务表格」模板生成，其中「详细情况」列取该订单**最新一条**详细情况；导出范围与当前可见数据一致（受角色数据范围限制）。

## 8. 删除与数据可见性

| 角色 | 可删除范围 |
|------|-----------|
| 话务员 / 话务员管理员 | 可删除**已录单**（状态=1）的订单（逻辑删除） |
| 管理员 | 可删除**任意**订单（即使已完成） |
| 收单员 / 收单员管理员 / 财务文员 | 默认不可删除订单 |

删除为**逻辑删除**：删除后订单不再出现在列表中，但数据仍在系统中保留。

## 9. 常见问题

**Q1：为什么我在列表里看不到某些订单？**
答：您只能看到自己职责范围内的订单（话务员看自己录的、收单员看派给自己的、管理员/收单员管理员/财务文员看全部）。若订单由其他同事处理，需联系对应角色。

**Q2：保存后为什么订单状态没有变化？**
答：「保存」只留存当前环节的字段，**不会改变订单状态**；如需保存并推进到下一状态，请使用「保存并下一步」按钮（该按钮仅在您有权限推进下一步时显示）。例如话务员录单后订单为「待排单」，需收单员管理员派单后才变为「已接单」。

**Q3：为什么我看不到某个操作按钮？**
答：操作按钮按「订单当前状态 + 您的角色」动态显示，只有您负责的环节才会显示对应按钮；「保存并下一步」也只在您有权限推进下一步时出现（如话务员录单时无派单权限，故只显示「保存」）。

**Q4：附件上传失败或数量超限怎么办？**
答：单个订单最多上传 5 个附件；请检查文件类型与网络后重试。

**Q5：详细情况误删了能恢复吗？**
答：不能。详细情况删除为逻辑删除且不可恢复，请谨慎操作。
